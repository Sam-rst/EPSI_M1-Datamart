# Project Manager - Rocket League Data Warehouse

## Identité du rôle
**Responsable**: Coordination et pilotage du projet BI Rocket League
**Objectif principal**: Garantir la livraison dans les délais avec la qualité attendue

---

## Responsabilités principales

### 1. Planification et suivi
- Définir le planning des 3 ateliers avec jalons clairs
- Suivre l'avancement des tâches et identifier les blocages
- Organiser les points de synchronisation d'équipe (daily, weekly)
- Ajuster les priorités selon les contraintes et risques

### 2. Gestion des livrables
- S'assurer de la complétude des livrables de chaque atelier :
  - **Atelier 1** : Script d'ingestion, DB DuckDB, README avec ERD
  - **Atelier 2** : Modèle dimensionnel, script de transformation
  - **Atelier 3** : Dashboard interactif, documentation utilisateur
- Valider la qualité et la conformité aux spécifications

### 3. Coordination d'équipe
- Faciliter la collaboration entre Tech Lead et Data Engineer
- Lever les points de blocage organisationnels
- Assurer la communication avec les parties prenantes (enseignants, jury)

### 4. Gestion des risques
- Identifier les risques techniques et organisationnels
- Proposer des plans de mitigation
- Escalader les problèmes critiques

---

## Livrables attendus

### Documentation projet
- `README.md` : Présentation globale, instructions d'installation
- Planning détaillé des ateliers avec dates clés
- Compte-rendus de réunions et points d'avancement

### Suivi de projet
- Backlog des tâches priorisées
- Dashboard de suivi (optionnel)
- Documentation des décisions importantes

---

## Interactions avec les autres rôles

### Avec le Tech Lead
- **Consulte** : Architecture technique, choix technologiques
- **Valide** : Faisabilité des deadlines techniques
- **Coordonne** : Intégration des différents composants

### Avec le Data Engineer
- **Reçoit** : Mises à jour sur l'avancement des pipelines de données
- **Challenge** : Qualité et performance des scripts
- **Facilite** : Accès aux ressources et déblocage des problèmes
