# Atelier 3 — Visualisation

## Objectif

Visualiser les indicateurs de performance via un Notebook ou une page web légère.

## Étapes

### 1. Indicateurs (KPIs)
Définir et implémenter **au moins 5 KPIs** avec au minimum 2 de chaque type :
- **Agrégation simple** : taux de victoire, durée moyenne, nombre de joueurs actifs…
- **Mesures croisées** : évolution du score moyen vs expérience, distribution des choix de personnages…
- Les mesures croisées doivent être représentées par un graphique pertinent (bar chart, line chart, heatmap…)

### 2. Filtres
- Permettre à l'utilisateur de **filtrer les données** d'un ou plusieurs graphiques selon **2 critères** au choix

### 3. Export de données
- Ajouter une fonctionnalité d'**export CSV** d'une vue spécifique des données analysées
